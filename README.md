# Meadow Egg Co. — Isometric Farm Tycoon

A responsive browser-based idle farm game made with plain HTML, CSS, JavaScript, and Canvas. It uses custom-drawn isometric-style art instead of emoji as the main graphics.

## Play
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select your `main` branch and `/(root)`, then save.
5. Open the published Pages URL after deployment finishes.

## Gameplay
- Chickens lay eggs automatically.
- Eggs are sold automatically for cash.
- Upgrade hen houses, feed, and delivery trucks.
- Progress is saved locally in your browser, including limited offline earnings.

No build tools, server, external assets, or libraries are required.
