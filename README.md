# Egg Farm Tycoon

A small browser-based egg-farm idle game built with plain HTML, CSS, and JavaScript. It is inspired by the **farm-management and incremental progression genre** and uses original styling and a simple emoji-based farm scene.

## Play locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment settings, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site; open the URL shown in the Pages section.

## How to play
- Tap **Hatch a chicken** to add chickens to your farm.
- Chickens produce eggs automatically.
- Delivery trucks automatically sell eggs for cash.
- Upgrade hen houses, feed, delivery trucks, and egg quality.
- The game saves progress in the browser on the device you play on.

This is a starter project, so the farm is illustrated with CSS and emoji rather than 3D models.
